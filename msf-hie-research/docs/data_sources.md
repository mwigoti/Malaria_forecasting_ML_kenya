# Data sources

This project uses epidemiological, environmental, and healthcare access data to support malaria forecasting and operational analysis.

## Recommended source documentation

- Provide provenance for each input dataset
- Record resolution, date range, and geographic coverage
- Describe quality checks and missingness thresholds
- Specify data access restrictions and ethical considerations

## Minimum metadata to capture

- Source name and owner
- Acquisition date
- Spatial and temporal granularity
- Key variables used in the analysis
- Processing steps applied before modeling
