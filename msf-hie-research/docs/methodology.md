# Methodology

This project follows a reproducible analytical workflow combining data validation, exploratory analysis, feature engineering, spatiotemporal modeling, and evaluation.

## Workflow summary

1. Validate and clean the source data
2. Inspect trends, seasonality, and anomalies
3. Engineer temporally and spatially relevant features
4. Train baseline and XGBoost forecasting models
5. Evaluate performance and compare approaches
6. Summarize hotspot and access-related findings

## Model outputs

The analysis should report:

- performance metrics (MAE, RMSE, MAPE, R² where appropriate)
- the feature set used for model training
- training and validation periods
- assumptions and limitations of the model
